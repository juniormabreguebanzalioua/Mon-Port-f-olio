Site web moderne et interactif

Un site web dynamique est un site web générée à la demande, par opposition à un site web statique. Le contenu d'un site web dynamique peut donc varier en fonction d'informations (heure, nom de l'utilisateur, formulaire rempli par l'utilisateur, etc.) qui ne sont connues qu'au moment de sa consultation.

Les langages Front-End, Back-End et l'éditeur utiliés sont:
